# 作成・編集機能の拡張

開始日: 2026-09-17。基点: `d19b18b056f0bca64bffb1bf02794abcc2af8591`。

## 承認された範囲

利用者の指定は [powerpoint-gap-analysis.md](powerpoint-gap-analysis.md) の P1 全18項目と、P2の G04/G10/G11/G12/G14/G18/G22/G24/G25/G40 の10項目、合計28項目。

作成・編集を優先し、発表・再生・動画、暗号化、クラウド共同編集は延期する。G35は静的PDF・画像・印刷を対象とする。G40はローカル文書内のコメント・返信・解決を対象とし、外部通知・認証サービスは追加しない。原本上書き、保護解除、保存先の無断変更、有料API利用、コミット・pushは行わない。

## 完了の定義

- コアだけでなく、利用者がStudioから操作でき、SDK・MCPでも同じ文書操作ができる。
- 実装した内容がネイティブPPTXへ保存され、再読込とUndoで内容・非対象XML・出典の整合性を維持する。
- 型・ユニット・統合・対象E2E、代表例のOffice表示を確認する。構造検証は視覚互換の保証ではない。
- 広いGapの一部を実装しただけなら「部分実装」とし、残る下位機能を明記する。
